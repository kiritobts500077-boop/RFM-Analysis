# RFM　ノート

**RFM**とは、顧客を購買行動で分類する分析手法です。主にマーケティングや顧客セグメント分析で使われます。

- **R（Recency：最終購入日）**
最近いつ購入したか
- **F（Frequency：購入頻度）**
頻繁に購入しているか
- **M（Monetary：購入金額）**
今までいくら使ったか

各項目を点数化し、たとえば次のように顧客を分類します。

| 顧客タイプ | 特徴 |
| --- | --- |
| 既存顧客 | 最近購入し、頻度・金額も高い |
| 新規顧客 | 最近購入したが、購入回数は少ない |
| 休眠顧客 | 以前は購入していたが、最近購入していない |
| 低関与顧客 | 購入頻度・金額に伴う低い |

この分析を使うと、顧客ごとに「リピート促進」「休眠顧客の掘り起こし」「既存顧客向け特典」など、施策を変えられます。

### 簡単な例

過去1年間の購入履歴から、次のような顧客を想定します。

| **顧客** | **最終購入** | **購入回数** | **購入金額** | **RFMの例** |
| --- | --- | --- | --- | --- |
| A | 10日前 | 8回 | 80,000円 | 555 |
| B | 15日前 | 1回 | 5,000円 | 511 |
| C | 240日前 | 7回 | 70,000円 | 155 |
| D | 180日前 | 1回 | 3,000円 | 111 |

この場合、Aには優良顧客向けの特典、Bには2回目の購入を促す案内、Cには再購入を促す案内、Dには低コストの情報提供など、それぞれに合ったアプローチが考えられます。点数や施策は一例です。実際には、商品や顧客の購買周期に合わせて調整します。

### **活用時の注意点**

**分析期間をそろえる**
「過去1年間」など、分析期間を定めて顧客同士を公平に比較します。

**商品や業種の購買周期を考慮する**
日用品と高額家電では、一般的な購入間隔が異なります。そのため、最終購入から90日経過した場合の意味も、商品によって異なります。

**売上だけでなく利益も見る**
購入金額が大きくても、値引きや返品が多ければ利益は小さい可能性があります。可能であれば、利益額や返品状況も確認しましょう。

**点数だけで顧客を決めつけない**
RFMは購買履歴を整理する手法であり、顧客の好みや満足度、問い合わせ内容、キャンペーンへの反応までは分かりません。必要に応じて、ほかの情報と組み合わせて判断します。

要するに、RFM分析は「**最近買う頻度・よく・少し・なし**」を整理し、顧客に合ったコミュニケーションや販促を検討するための基本的な手法です。
