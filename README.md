# RFM　ノート

**RFM**とは、顧客を購買行動で分類する分析手法です。主にマーケティングや顧客セグメント分析で使われます。

- **R（Recency：最終購入日）**
最近いつ購入したか
- **F（Frequency：購入頻度）**
頻繁に購入しているか
- **M（Monetary：購入金額）**
今までいくら使ったか

各項目を点数化し、たとえば次のように顧客を分類します。

| 顧客タイプ | 特徴 |
| --- | --- |
| 既存顧客 | 最近購入し、頻度・金額も高い |
| 新規顧客 | 最近購入したが、購入回数は少ない |
| 休眠顧客 | 以前は購入していたが、最近購入していない |
| 低関与顧客 | 購入頻度・金額に伴う低い |

この分析を使うと、顧客ごとに「リピート促進」「休眠顧客の掘り起こし」「優良顧客向け特典」など、施策を変えられます。
